# Lead — Product & Project Lead

**Reference:** full system design in *Architecture*

### 🎯 Mission

Own product vision, source real property data, keep all 5 other roles unblocked and in sync, make the launch call.

---


### Day 1 — Kickoff

- [ ] Finalize business name, domain, brand colors/logo
- [ ] Lock MVP scope — communicate any cuts to the whole team
- [ ] Confirm all 5 teammates onboarded to their pages
- [ ] Set daily standup time
- [ ] Share brand assets with UI/UX Design and Frontend

### Day 2 — Shared Resources

- [ ] Set up shared Drive: seller contacts, doc templates, property data
- [ ] Share document checklist context with Backend

### Day 2–4 — Property Sourcing

- [ ] Reach out to existing contacts — source 5-10 real properties (land + flats)
- [ ] Collect property details + documents from these sellers
- [ ] Prep data handoff to Content & Bilingual by Day 5

### Daily (all week)

- [ ] Run standup — unblock Backend/Frontend/Design/Content/QA
- [ ] Track sprint risks, flag early

### Day 5

- [ ] Review content (EN + TE) as finalized
- [ ] Confirm handed-off property data is accurate/complete

### Day 6

- [ ] Line up 1-2 real sellers/buyers for UAT with QA
- [ ] Full personal walkthrough of the staging site
- [ ] Finalize domain/hosting/SSL with Backend
- [ ] Review pre-launch checklist with QA
- [ ] Make go/no-go call

### Day 7 — Launch

- [ ] Coordinate go-live timing across team
- [ ] Announce launch (WhatsApp, contacts, socials)
- [ ] Monitor enquiries — confirm routing works
- [ ] 🎉
