# UI/UX Design — Designer

**Reference:** full system design in *Architecture*

### 🎯 Mission

Design a trust-first, mobile-optimized experience for a brokerage (not a marketplace). Design ahead of Frontend build so dev never waits on you.

---


### Day 1 — Foundations

- [ ] Confirm brand colors/logo with Lead
- [ ] Set up design file (Figma): type scale, color palette, spacing system
- [ ] Wireframe homepage: hero, value prop, featured properties, trust badges, nav
- [ ] Hand off homepage design to Frontend

### Day 2 — Forms

- [ ] Design seller "List your property" multi-step form
- [ ] Design document upload UI (checklist-style, 13 items, status indicators)
- [ ] Hand off to Frontend

### Day 3 — Search & Browse

- [ ] Design buyer search/listing page: filters, property cards, sort
- [ ] Design map view layout (list + map split view)
- [ ] Hand off to Frontend

### Day 4 — Detail & Enquiry

- [ ] Design property detail page: gallery, info layout, verified badge, CTAs
- [ ] Design enquiry form + confirmation state
- [ ] Design trust elements: testimonials, "About us"/team profile

### Day 5

- [ ] Design team back-office dashboard (enquiry list, status updates)
- [ ] Review built pages against designs, flag discrepancies to Frontend

### Day 6

- [ ] Mobile design pass — verify all pages at small screen sizes
- [ ] Check Telugu text length doesn't break layouts (coordinate with Content)
- [ ] Design QA: walk through staging site, log visual bugs

### Day 7

- [ ] Final design sign-off
- [ ] Support Frontend with last-minute UI fixes

---


### 🎨 Design Principles

* Trust over flash — clean, credible, not "salesy"
* Mobile-first
* Verified checkmarks/status indicators prominent everywhere
* "Book a site visit" is the most visually dominant CTA
* No clutter

---


### 🔗 Dependencies

* Brand assets from Lead by Day 1
* Content's copy length estimates (EN+TE) by Day 2
* Deliver designs 1 day ahead of Frontend's matching build day
